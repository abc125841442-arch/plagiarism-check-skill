# plagiarism-check

An [Agent Skill](https://skills.sh) for detecting copied or duplicated text — local similarity, n-gram fingerprinting, and online checkers.

```
npx skills add <your-github-user>/plagiarism-check
```

## What it does

- **Jaccard shingle similarity** — catches reordering
- **3-gram cosine fingerprinting** — catches light paraphrase
- **Interpretation** — high score ≠ plagiarism; check passages
- **Workflow** for academic integrity and content review

See [`SKILL.md`](./SKILL.md) for the full instructions.
